## 🚀 Como Funciona a Fábrica de Louvores:

1. **GPU Gratuita na Nuvem:** O Kaggle cede **30 horas semanais** de GPU NVIDIA Tesla T4 (16 GB) ou P100 (16 GB).
2. **Seu Computador Fica Leve:** Toda a síntese pesada da voz, batidas 808 e arranjo roda nos servidores do Kaggle.
3. **Download Direto para a Playlist:** O script baixa as músicas finalizadas direto para `C:\Users\matheus\Music\Playlist MATHEUS`, e a plataforma do Ministério Metanoia já reconhece a nova faixa no mesmo instante!

---

## 💻 Como Usar pelo Terminal / Windows:

### Opção 1: Atalho Rápido no Windows
Basta dar um clique duplo no arquivo:
👉 [`3_GERAR_LOUVOR_KAGGLE.bat`](file:///c:/Users/matheus/Desktop/ministerio/3_GERAR_LOUVOR_KAGGLE.bat)

Ele abre um menu interativo no seu terminal:
* **[1] Subir/Atualizar Notebook no Kaggle:** Envia alterações do notebook com 1 clique (`kaggle kernels push`).
* **[2] Verificar Status do Kernel:** Vê se a GPU está rodando ou se a música terminou de ser gerada.
* **[3] Baixar Músicas do Kaggle:** Puxa os arquivos `.mp3` gerados e salva na sua pasta oficial `Playlist MATHEUS`.
* **[4] Abrir Kernel no Navegador:** Abre a página do Kaggle para ver os logs ou usar a interface visual.

---

### Opção 2: Usar a Interface Visual no Navegador (WebUI Gradio)
1. Abra o kernel no Kaggle: [https://www.kaggle.com/code/omatheusbsilva/metanoia-yue-music-generator](https://www.kaggle.com/code/omatheusbsilva/metanoia-yue-music-generator)
2. Clique em **"Edit"** para abrir o notebook no modo interativo com GPU T4 ligada.
3. Ao rodar a célula do Gradio, será gerado um link público:  
   `Running on public URL: https://xxxx.gradio.live`
4. Abra esse link, digite a letra do louvor e o estilo do 2metro (`Brazilian trap gospel, heavy 808, acoustic guitar`), clique em **Generate** e ouça a música na hora!
